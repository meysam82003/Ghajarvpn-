# بازبینی رابط ۳.۰.۱

- لوگوی طلایی شفاف، ولکام کامل بدون برش و ورود نرم.
- وزیر خزانه‌داری در فروشگاه؛ نمادهای برداری قاجاری و نوار پایین گرد.
- منبع رایگان فقط `https://t.me/s/Ghajarvpn` است. نبود کانفیگ، منبع جایگزین ایجاد نمی‌کند.
- Aether موتور تونل است، نه کانال کانفیگ. اعتبار سازندهٔ آن، CluvexStudio،
  محفوظ است؛ عنوان کانال‌مانند از صفحهٔ پروژه‌های رایگان حذف شده است.
- اتصال ربات مطابق ZIP کامل ارسالی: `?start=link_123456`؛ کاربر هنوز باید
  دکمهٔ Start تلگرام را تأیید کند. فرمان `/link 123456` بدون ویرایش قابل کپی است.
- اعلان سراسری زیر سربرگ همهٔ صفحات، صف پیام‌ها، تأیید خواندن مستقل از اعلان گوشی.
- خرید، سرویس‌های من و پیام‌ها جدا؛ توضیحات جمع‌شونده و تأیید قبل از خرید.
- قیمت ناموجود «رایگان» فرض نمی‌شود. ارقام فارسی/عربی برای خرید سفارشی پذیرفته می‌شوند.
- سقف رندر CPU کره از ۷۶۸ به ۳۸۴ کاهش یافته؛ حرکت مقصد ۵۵۰ میلی‌ثانیه است.

## مرز تست

دمو Android 8+ است؛ هستهٔ بسته‌بندی‌شده هنوز مانع ادعای پشتیبانی Android 7 است.
CI کامپایل، آزمون قرارداد لینک و ورودی عددی و بازسازی پچ‌ها را بررسی می‌کند.
بررسی روی گوشی، فونت بزرگ، نمایش افقی، روانی کره و پرداخت واقعی هنوز لازم است.
هیچ خرید، پرداخت یا پیام تلگرامی به‌جای کاربر در زمان توسعه ارسال نشده است.
