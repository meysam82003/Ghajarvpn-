# ساخت و بررسی دموی قاجار

این مخزن با اجرای اسکریپت بازسازی، سورس کامل اندروید را از upstream ثابت و پچ‌های مرورشده می‌سازد. فایل‌های خوانای ریشه جایگزین سورس کامل نیستند؛ CI تطابق آن‌ها با نسخهٔ بازسازی‌شده را بررسی می‌کند.

## ساخت دمو

```bash
scripts/bootstrap-from-upstream.sh
.ghajarvpn-src/scripts/fetch-openvpn-native.sh .
bash scripts/verify-source-snapshots.sh .ghajarvpn-src
cd .ghajarvpn-src
./gradlew --no-daemon -Pghajar.demo=true :app:assembleDebug
```

اسکریپت دریافت موتور، ریشهٔ بسته را می‌گیرد و خودش پوشهٔ `.ghajarvpn-src` را اضافه می‌کند؛ همان پوشه را دوباره به آن ندهید.

فقط پس از موفقیت کامل CI، فایل‌های APK در Artifact با نام `Ghajarvpn-demo-Android8plus` قرار می‌گیرند. این نسخه با امضای debug ساخته می‌شود و انتشار نهایی نیست. کلید debug محیط محلی و GitHub ممکن است متفاوت باشد؛ نصب یکی روی دیگری ممکن است خطای امضا بدهد. پیش از حذف نسخهٔ قبلی از تنظیمات و کانفیگ‌های موردنیاز بکاپ بگیرید.

## محدودهٔ سازگاری

- دمو با فلگ `ghajar.demo=true` حداقل API 26 (Android 8) و نسخهٔ `3.0.0-demo` دارد؛ این حداقل با AAR هستهٔ فعلی منطبق است.
- Android 7 / API 24 همچنان هدف نسخهٔ نهایی است، نه قابلیت تأییدشده. ساخت عادی این هدف را حفظ می‌کند و تا زمان بازسازی هستهٔ سازگار، بررسی Manifest نباید با `overrideLibrary` خاموش شود.
- موفقیت کامپایل، تأیید اتصال VPN، پرداخت واقعی یا سازگاری همهٔ دستگاه‌ها نیست.

## بررسی روی گوشی

۱. از صفحهٔ اصلی، فروشگاه، حساب، تنظیمات و اعلان‌ها اسکرین‌شات بگیرید؛ نسخهٔ Android و مدل گوشی را همراهشان بنویسید.
۲. روشن/تاریک، متن فارسی و بزرگ‌نمایی فونت را بررسی کنید.
۳. ورود حساب، بارگذاری قیمت واقعی و تحویل کانفیگ را ابتدا با حساب آزمایشی بررسی کنید؛ برای بررسی ظاهری پرداخت واقعی لازم نیست.
۴. اجازهٔ VPN و اعلان، واردکردن OVPN و بازگشت از صفحهٔ پرداخت باید جداگانه آزمایش شوند.

مرجع قرارداد ربات و مینی‌اپ، فایل کامل `Ghajar_vpnbot_-3-1.zip` ارسالی صاحب پروژه است. سورس کامل backend و اطلاعات حساس آن به این مخزن عمومی اضافه نشده‌اند.
