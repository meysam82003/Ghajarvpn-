# بازسازی سورس کامل از GitHub

مخزن اصلی چند موتور بومی و فایل باینری بزرگ دارد. برای جلوگیری از ناقص‌شدن انتقال با API، GitHub می‌تواند سری تغییرات بررسی‌شدهٔ قاجار را روی یک کامیت ثابت از پروژهٔ پایه اعمال کند.

```bash
./scripts/bootstrap-from-upstream.sh
cd .ghajarvpn-src
./gradlew :app:assembleDebug
```

اسکریپت مقصد موجود را حذف یا بازنویسی نمی‌کند. اگر `.ghajarvpn-src` از قبل وجود داشته باشد، با خطا متوقف می‌شود. هش مبنا ثابت است و سری پچ باینری شامل کد OpenVPN، تغییرات رابط، لوگوها و تنظیمات برند است.

در نسخهٔ کامل آرشیوی، فایل‌های موتور از قبل وجود دارند و نیازی به اجرای این اسکریپت نیست.
