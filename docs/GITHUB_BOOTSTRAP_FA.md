# بازسازی سورس از GitHub (منسوخ)

این سند به یک معماری بازنشسته اشاره می‌کرد: بازسازی درخت ساخت در زمان CI از یک fork بالادستی ثابت به‌علاوهٔ اعمال یک سری پچ. آن معماری و اسکریپت `scripts/bootstrap-from-upstream.sh` دیگر در این مخزن وجود ندارند.

از commit `c1e2c3eb113b942a68e0267fdc8c32924e97397c` (ریلیز ۱.۰.۰) به بعد، شاخهٔ `main` این مخزن **کامل و خودکفاست**: تمام سورس اپلیکیشن اندروید، ماژول‌های OpenVPN و strongSwan، AAR موتور، و بک‌اند Faoxima مستقیماً در همین مخزن commit شده‌اند. برای ساخت:

```bash
./gradlew :app:assembleDebug
```

هیچ کلون یا اعمال پچی از یک مخزن دیگر لازم نیست. جزئیات کامل provenance و نگاشت مسیرها در [`SOURCE-POLICY.md`](../SOURCE-POLICY.md) در ریشهٔ مخزن آمده است.
