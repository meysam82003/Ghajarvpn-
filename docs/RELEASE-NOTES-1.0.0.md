# Ghajarvpn 1.0.0

- لمس کوتاه کاشی VPN برای اتصال و قطع؛ نگه‌داشتن آیکون برای بازکردن اپ.
- رفع خطای بسته‌شدن اپ هنگام بازکردن پرداخت بلوپال.
- پرداخت‌های در انتظار تأیید، ادامهٔ پیگیری همان فاکتور و انصراف با تأیید سرور.
- تاریخچهٔ تراکنش‌های کیف پول با صفحه‌بندی.
- دریافت کانفیگ و ساب از کانال‌های انتخاب‌شده؛ بررسی حداکثر ۳۵۰ کانفیگ یکتا و افزودن موارد پاسخ‌گو با نام Ghajarvpn و شماره.
- اصلاحات فروشگاه و اتصال حساب، اعلان‌ها، تیکت، سهمیهٔ مستقل تست هر پنل و بازگشت وجه خرید ناموفق.
- تنظیمات اتصال Oblivion و سایفون.

فایل‌های همراه: APKهای ARM64 و ARMv7، سورس کامل اپ شامل ماژول‌ها و منابع هسته‌ها، سورس کامل ربات و مینی‌اپ Faoxima، اصلاحیهٔ سرور و SHA256SUMS.txt.

آرشیو complete-source پروژهٔ کامل است و برای دریافت فایل‌های اصلی به اعمال overlay نیاز ندارد. راهنمای ساخت و فهرست هش فایل‌ها داخل آن قرار دارد.
