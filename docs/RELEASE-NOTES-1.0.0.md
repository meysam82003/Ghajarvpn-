# Ghajarvpn 1.0.0

## تغییرات
- هماهنگی فروشگاه و ورود با کد با Faoxima 1.0.0؛ اصلاحیهٔ سرور همراه فایل‌هاست.
- اعلان‌های درون‌برنامه‌ای و معمولی مطابق API جدید، پشتیبانی و تیکت و دسترسی به پنل کامل داخل اپ.
- دریافت کانفیگ و لینک اشتراک فقط از کانال @Ghajarvpn؛ نام کانفیگ‌ها `Ghajarvpn` و شماره است.
- حذف پنل غیرفعال از تست در ربات، مینی‌اپ و اپ. سقف تست برای هر کاربر در هر پنل مستقل است؛ درخواست‌های هم‌زمان سهمیهٔ اضافی نمی‌گیرند.
- اصلاح انتقال تنظیمات و پورت واقعی سایفون به سرویس VPN؛ انتظار برای اتصال واقعی، افزودن کشور و تنظیمات CDN IP/SNI.
- تنظیمات Android در Oblivion شامل MASQUE/WireGuard/gool، حالت زنجیره‌ای Aether و سایفون، DNS، پروکسی محلی، فرگمنت، مسیریابی، کارایی و Zero Trust.
- بازگشت تراکنشی مبلغ خرید ناموفق به کیف پول و جلوگیری از شارژ تکراری؛ بررسی سرویس موجود پس از قطع پاسخ پنل.
- اصلاح لغو اتصال و پاک‌سازی هسته برای تلاش‌های مجدد.

## وضعیت این خروجی
این Release تا تکمیل موارد زیر به‌صورت پیش‌نویس نگهداری می‌شود:
- نصب `Ghajarvpn-1.0.0-server-patch.zip` روی سورس Faoxima سرور. مسیر `api/weblink.php` در سرور بررسی‌شده 404 بود؛ تغییر سورس اندروید به‌تنهایی آن را ایجاد نمی‌کند.
- بررسی عملی ورود تلگرام، اعلان، تیکت و اتصال سایفون روی گوشی؛ این موارد با حساب و گوشی واقعی اجرا نشده‌اند.
- تعیین امضای نهایی اپ: APKهای CI با کلید آزمایشی ساخته می‌شوند و نصب به‌عنوان به‌روزرسانی نسخهٔ قبلی تضمین نمی‌شود.

Conduit در سورس Oblivion ارسالی کلید امضای لازم را ندارد و در این نسخه قابل استفاده نیست. حالت‌های خودکار، CDN و مستقیم در تنظیمات اپ قرار دارند. حالت زنجیره‌ای Aether و سایفون نیز اضافه شده است.

سورس و نتایج آزمون‌ها در Pull Request شمارهٔ ۱ و اجرای Android CI همین commit قابل بررسی است. فایل `SHA256SUMS.txt` هش خروجی‌ها را مشخص می‌کند.
