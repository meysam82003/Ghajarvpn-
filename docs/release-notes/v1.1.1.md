# 👑 قاجار VPN نسخهٔ 1.1.1 (نسخهٔ سبک)

**روی 1.0.10 نصب می‌شود** (همان کلید امضا). کانفیگ‌ها، اشتراک‌ها، تنظیمات و ظاهر شخصی‌سازی‌شده حفظ می‌شوند. `versionCode` از 30025 به 30026 رسید.
APK جدا برای `arm64-v8a` و `armeabi-v7a`. فایل SHA256SUMS.txt کنار فایل‌ها منتشر شده است.

| بخش | تغییر |
|---|---|
| 🪶 نسخهٔ سبک | تونل‌های DNS (DNSTT، VayDNS، NoizDNS، MasterDNS، StormDNS، CottenDNS، Slipstream)، DNS Lab، اسکنر DNS، حالت DNS-only، Juicity، بررسی nDPI و کتابخانهٔ تست سرعت OpenSSL حذف شدند |
| 🛡 هسته‌های حفظ‌شده | Xray 26.3.27، sing-box، Psiphon، Tor با obfs4/meek/webtunnel/snowflake، Aether، IKEv2، OpenVPN، OpenConnect، WireGuard و AmneziaWG بدون حذف |
| 📦 کانفیگ‌های قدیمی | پروفایل روش‌های حذف‌شده پاک نمی‌شوند. با برچسب «در 1.1.1 موجود نیست» در فهرست می‌مانند و هنگام اتصال پیام می‌دهند: «این روش در نسخه سبک 1.1.1 داخل برنامه اصلی موجود نیست.» |
| ⚙️ تنظیمات | ۹ بخش (اتصال، هسته و پروتکل، اشتراک‌گذاری، شخصی‌سازی، فروشگاه و حساب، پشتیبان، اعلان‌ها، لاگ و عیب‌یابی، درباره) و **جستجوی سریع** |
| 📤 اشتراک‌گذاری | صفحهٔ تازه: خروجی کانفیگ برای Android، iPhone، iPad، Windows، macOS، Linux و Router با راهنمای مرحله‌به‌مرحله؛ پورتال یک‌بارمصرف شبکهٔ محلی |

| 🔒 GSB2 | اشتراک امن تازه با فایل `.gsb2`: رمز، تاریخ پایان، مدت اعتبار، سقف حجم و پنهان‌کردن سرور. همه در گوشی گیرنده اعمال می‌شوند |
| 📥 ایمپورت | فایل پروفایل sing-box (`.bpf`) با حفظ کامل کانفیگ؛ پسوند `.npvts` |
| 🧭 Psiphon | انتخاب پروتکل تونل از فهرست واقعی داخل خود کتابخانه؛ رد شدن پروتکل QUIC پشت زنجیرهٔ Aether پیش از اتصال |
| 🔔 اعلان | «قاجار VPN روشن شد» و «قاجار VPN خاموش شد»؛ نمایش سرور، پروتکل، هسته، مدت اتصال و مصرف؛ دکمه‌های سرور بعدی، اتصال مجدد و قطع |
| ⬆️ بروزرسانی | دانلود واقعاً modal (فقط «لغو دانلود» آن را متوقف می‌کند)؛ نصب فقط بعد از تأیید SHA-256 و امضا؛ دکمهٔ «بروزرسانی جدید» در صفحهٔ اصلی؛ تاریخچهٔ نسخه‌ها در «درباره»؛ یادآوری بروزرسانی (پیش‌فرض روشن) |
| 🎨 ظاهر | دکمهٔ اتصال «حلقه» و «فشرده»؛ ویزارد ۷ مرحله‌ای برای نصب اول (روی بروزرسانی از 1.0.10 نمایش داده نمی‌شود) |
| 🐞 رفع اشکال | App Proxy و Logcat با یک لمس باز می‌شوند؛ صفحهٔ لاگ برای متن‌های طولانی واکنش‌گرا شد؛ کد تخفیف در یک خط قابل انتخاب است و دکمهٔ کپی دارد؛ مبلغ تمدید با پیش‌فاکتور ارزی یکی است؛ فهرست سرویس‌ها بیش از ۱۰۰ سرویس را هم نشان می‌دهد |
| 🧾 مجوزها | مجوزهای Location، میکروفون و حافظهٔ قدیمی از manifest نهایی حذف شدند |
| 🧹 لاگ | توکن‌ها، رمزها، Basic/Bearer، کوکی و لینک اشتراک پیش از ورود به حافظه، logcat و فایل حذف می‌شوند |

## ⚠️ محدودیت‌ها

- GSB2 بدون پنل است: لغو از راه دور، دیدن تعداد افراد وصل، تغییر رمز و سقف دستگاه ندارد.
- اشتراک از طریق گوشی فقط وقتی کار می‌کند که اتصال روی Xray باشد (همین‌طور Psiphon، Tor و Aether). اتصال‌های sing-box، OpenVPN و IKEv2 درگاه اشتراک ندارند.
- افزونهٔ هسته در این نسخه منتشر نشده است.
- ممیزی ZedSecure فقط مستند شده است و هیچ کدی از آن وارد نشده: `docs/zedsecure-audit/`.
