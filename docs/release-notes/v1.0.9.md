# 👑 GhajarVPN 1.0.9

**Installs over every earlier version** with the same signing key; configs, subscriptions and settings are kept.
`versionCode` goes from 30023 to 30024. This release includes everything in 1.0.7 and 1.0.8, which were built but never published separately.

> For the shops section to work fully, the bot side must have **bot v18** installed (tick, shop reports, "my shops", public discount codes). Earlier bot versions work, but these parts stay empty.

## 🧩 4. Widget

- **Scrollable** list of the selected config's subscription configs, right in the widget.
- Ping measures the active config and then every row; subscription refresh redraws the list.
- Tapping a row selects that config and **connects** (it switches if a tunnel is already up).

## 💳 6. Payment

- **Every shop** pays like the official Ghajar shop: tracking code, amount, "continue this payment", "I paid; check it", "Cancel". **No gateway link or host is shown.**
- Inside a payment, any plain HTTPS page the gateway redirects to is allowed (a URL containing a username/password, a non-443 port, or non-HTTPS is still refused), so the **"This address is not in the payment domain list"** error no longer appears in the official shop.
- **"Back to app"** on the payment page (`ghajarvpn://payment-return`) is registered: it returns to the shop tab and re-checks orders.

## 🩺 7. Troubleshooting and map

- **Fix automatically:** no internet → opens network settings; DNS broken → encrypted 1.1.1.1 and reconnect; server unreachable/timeout → pings the subscription's other servers and connects to the **fastest**; core error → restart; then it checks again.
- **Map:** the IP lookup is done through the same working home-screen path (through the tunnel if one is up), then the pin is refined.

## 📦 8. Size and smoothness

- Large images converted to WebP (−2.4 MB) and library translations limited to English and Persian.
- The optimised build (R8 + baseline profiles) is used for the release; zero-cost animations while idle.
