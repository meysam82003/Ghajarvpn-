# یادداشت‌های منتشرنشده

این سه فایل یادداشت نسخه‌هایی هستند که **هیچ‌وقت به‌عنوان Release جداگانه منتشر
نشدند**. کارهایی که در آن‌ها توصیف شده روی شاخهٔ
`feature/next-release-vpn-share-updater-renewal-usage` ساخته شد و محتوایش داخل
نسخه‌های منتشرشده رفت، نه زیر شمارهٔ خودش.

اینجا نگه داشته می‌شوند چون شرح دقیق آن کارها جای دیگری نوشته نشده و حذفشان یعنی
از دست دادن تنها سابقهٔ مکتوب چند قابلیت. شمارهٔ روی نام فایل، شمارهٔ برنامه‌ریزی
شدهٔ همان زمان است و با نسخه‌های واقعاً منتشرشده در پوشهٔ بالاتر یکی نیست.

برای فهرست نسخه‌های واقعی به
[صفحهٔ Releases](https://github.com/meysam82003/Ghajarvpn-/releases) یا فایل‌های
`../v1.0.*.md` نگاه کن.
