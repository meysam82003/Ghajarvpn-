## اضافه شد

| قابلیت | کارش چیست |
| --- | --- |
| آزمایشگاه دی‌ان‌اس | ۲۶ دی‌ان‌اس روی UDP، TCP، DoT و DoH با پرسش واقعی اندازه‌گیری می‌شوند، و آن‌هایی که برای نام فیلترشده آدرس قلابی برمی‌گردانند علامت می‌خورند و قابل انتخاب نیستند |
| انتخاب دی‌ان‌اس | دی‌ان‌اس انتخاب‌شده جلوی پیش‌فرض‌ها قرار می‌گیرد، نه جای آن‌ها |
| تنظیم اندازهٔ فرگمنت | چهار حالت آماده برای فرگمنتور TLS |
| چرخش بین سرورها | هر ۱۵، ۳۰، ۶۰ یا ۱۲۰ دقیقه بین سرورهای خودت جابه‌جا می‌شود |
| Cipher suites | فهرست رمزهای TLS برای هر کانفیگ، اختیاری |
| ساب‌دامین تصادفی | در هر اتصال یک برچسب تصادفی جلوی SNI (برای سرورهای با گواهی wildcard) |

## رفع شد

| مشکل | توضیح |
| --- | --- |
| تنظیمات فرگمنت به موتور نمی‌رسید | مقادیرش در برنامه ذخیره می‌شد، جایی نشان داده نمی‌شد و **هرگز** به هسته پاس نمی‌شد؛ فرگمنتور همیشه روی مقادیر پیش‌فرض کار می‌کرد |
| پنجرهٔ تمدید اسکرول نمی‌شد | بدنه‌اش به کسری از ارتفاع صفحه محدود بود نه پنجرهٔ خود دیالوگ، پس سرریز می‌کرد و دکمه‌ها روی آخرین گزینه می‌افتادند |
| فایل و کیوآر در «کانفیگ دارم» دیده نمی‌شد | پنل باز در ستون ثابت بریده می‌شد؛ حالا اسکرول می‌شود |
| ترتیب افزودن سرور | کانفیگ دارم، سایفون، OpenVPN، پروژه‌های رایگان، وینداسکرایب |

## هیچ چیزی حذف نشد

همهٔ موتورها و قابلیت‌های قبلی سر جایشان هستند. دی‌ان‌اس رمزنگاری‌شده و fake DNS همان کلیدهای قبلی‌اند؛ اگر دی‌ان‌اسی انتخاب نکنی، تونل بایت‌به‌بایت همان تنظیم قبلی را می‌سازد. چرخش سرور پیش‌فرض خاموش است و کانفیگ‌های OpenVPN و IKEv2 را دست نمی‌زند. `cipher suites` و ساب‌دامین تصادفی روی همهٔ کانفیگ‌های موجود خالی و خاموش‌اند.

## دربارهٔ مجوزها

MahsaNG و PattNG هر دو GPL-3 هستند و این برنامه هم GPL-3 است، پس سازگارند. zeptun هم MIT است. WhiteDNS-Android انحصاری است و لایسنسش کپی کردن در محصول دیگر را ممنوع کرده، پس هیچ چیزی از آن استفاده نشده؛ کدک DNS و اسکنر این نسخه از صفر روی خود RFC نوشته شده‌اند.
