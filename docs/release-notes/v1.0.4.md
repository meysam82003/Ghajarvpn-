# GhajarVPN 1.0.4

روی هر نسخهٔ قبلی نصب می‌شود؛ با همان کلید امضا شده و کانفیگ‌هایت پاک نمی‌شوند.
`versionCode` از ۳۰۰۱۸ به ۳۰۰۱۹ رفته است.

این نسخه **هیچ قابلیتی اضافه نمی‌کند**. حاصل یک عیب‌یابی کامل کرش روی چیزی است که
در ۱.۰.۳ منتشر شد، و دو ایرادی که پیدا شد هیچ‌کدام گزارش نشده بودند.

## ۲. تست OpenVPN، و یک مسابقه

`testSaved` دو بار `_tests.value` را می‌خواند: یک‌بار برای پرسیدن «تستی در جریان
است؟» و بار دوم برای برگرداندنِ همان، با `!!`.

بین آن دو خواندن، تستِ در جریان می‌توانست تمام شود و کلیدش را پاک کند. آن‌وقت
شرط `running == true` جواب می‌داد و خطِ بعد روی کلیدی که دیگر نبود `!!` می‌زد —
یعنی کرش. دو ضربه روی «تست» کافی بود.

حالا یک خواندن.

## چیزهایی که ممیزی شدند و سالم بودند

این فهرست اینجاست چون «بررسی کردم» بدون گفتن اینکه چه چیزی، حرفِ بی‌پشتوانه است:

| بررسی | نتیجه |
| --- | --- |
| هر `R.id` که ویجت‌ها استفاده می‌کنند در layout هست | ✅ اگر نبود، ویجت موقع رندر کرش می‌کرد |
| هر Activity/Service/Receiver که با Intent اجرا می‌شود اعلام شده | ✅ سه تای باقی‌مانده از manifest کتابخانه‌های OpenVPN و strongSwan می‌آیند |
| `first()`/`last()` بدون محافظ | ✅ هیچ‌کدام — همه یا داخل یک شرط ناتهی‌بودن‌اند یا روی چیزی که همیشه حداقل یک عضو دارد |
| بقیهٔ یازده `!!` | ✅ همه بلافاصله بعد از یک انتساب یا یک بررسی null، بدون چیزی در میان |
| `registerReceiver` بدون فلگ صادرات (کرش اندروید ۱۴) | ✅ وجود ندارد |
| خواندن‌های JSON در `ConfigStore` | ✅ داخل try |
| `verticalScroll` داخل آیتم لیست (کرشِ ۱.۰.۳) | ✅ فقط همان یکی بود، و در ۱.۰.۳ رفع شد |

## تصحیح یادداشت ۱.۰.۳

در یادداشت ۱.۰.۳ نوشته بودم برای جدول `user_notice` باید یک‌بار `table.php` اجرا
شود. **درست نبود.** `FaoximaNotices` خودش `CREATE TABLE IF NOT EXISTS` دارد و هر
شش نقطهٔ ورودی‌اش قبل از کار آن را صدا می‌زند. همین‌طور `app_link_session`،
`app_web_ticket` و جدول‌های سهمیهٔ تست.

ستون `usertest_scope` هم حالا مثل `force_app_*` خودش ساخته می‌شود، تا آن هم بی‌صدا
از کار نیفتد.

**هیچ قدم دستی روی دیتابیس لازم نیست.** فقط فایل‌های ربات را آپلود کن.

## تست نشده روی دستگاه

بیلد، تست‌های واحد و بررسی امضا سبز هستند. اعلان‌ها، ویجت‌ها و تونل روی گوشی
واقعی آزمایش نشده‌اند. هر دو ایرادی که اینجا رفع شد از خواندن کد پیدا شد، نه از
دیدنشان روی گوشی.
