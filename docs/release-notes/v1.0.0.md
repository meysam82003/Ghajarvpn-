# قاجار VPN ۱.۰.۰ — نسخه پایه جدید

این انتشار، مجموعه تغییرات شاخه توسعه را به‌عنوان نسخه پایه جدید ارائه می‌کند. کد نسخه اندروید `30015` است؛ این عدد از کد نسخه انتشار قبلی (`30009`) بالاتر نگه داشته شده تا امکان به‌روزرسانی اندروید حفظ شود. نام نمایشی برنامه `1.0.0` است.

| بخش | تغییرات |
| --- | --- |
| رابط کاربری | بازطراحی صفحه اصلی و فروشگاه، لوگوی طلایی و صفحه شروع جدید، نمایش پروتکل و سرور فعال، بهبود انیمیشن‌های فهرست و پینگ |
| اتصال و عیب‌یابی | عیب‌یاب اتصال، قوانین خودکار شبکه، بازیابی هنگام تغییر Wi-Fi و داده تلفن، انتخاب و چرخش سرورها |
| VPN Share و امنیت | راه‌اندازی مرحله‌ای اشتراک VPN، گزارش وضعیت Kill Switch، DNS و IPv6، ویجت اتصال روی صفحه اصلی |
| حساب و اشتراک | نمایش درصد حجم و زمان آخرین به‌روزرسانی، تمدید از فهرست سرویس‌ها و جزئیات طرح در صفحه تمدید |
| DNS | آزمایشگاه ریزالورها، تشخیص پاسخ مشکوک، واردکردن فهرست، تونل DNS-only و انتخاب مجدد خودکار ریزالور ناموفق در انتخاب خودکار؛ انتخاب دستی محفوظ می‌ماند |
| تنظیمات پیشرفته | تنظیم اندازه فرگمنت، ماسک‌ها و نویز، ECH در صورت پشتیبانی سرور، تنظیمات zeptun و YouTube Direct اختیاری |
| موتورهای اتصال | موتورهای پیشین حفظ شده‌اند؛ zeptun برای انتقال TUN به SOCKS در حالت‌های سازگار و فایل هسته sing-box در بیلد اندروید گنجانده شده‌اند |
| به‌روزرسانی | خواندن توضیحات نسخه به شکل جدول و بررسی فایل APK متناسب با معماری و SHA-256 هنگام نصب |

**وضعیت آزمایش:** ساخت Debug در GitHub Actions برای کامیت مبنا `946d71a9ad689be6cb175c9af6c8f3b10a33589a` موفق شده است. این نتیجه جایگزین تست عملی همه موتورهای اتصال روی گوشی و آزمایش فایل Release امضاشده نیست. حضور فایل sing-box در APK به‌تنهایی به معنای کامل‌بودن رابط اتصال همه پروتکل‌های آن نیست.

**نصب و امضا:** APK انتشار باید با کلید امضای اصلی و همان package name ساخته شود. استفاده‌کنندگان نسخه Debug با امضای متفاوت ممکن است برای نصب نسخه رسمی به پشتیبان‌گیری از تنظیمات و نصب مجدد نیاز داشته باشند.
