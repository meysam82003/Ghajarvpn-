## این پروژه چیست

سه چیز که به هم وصل‌اند:

| | چه کاری می‌کند |
| --- | --- |
| **اپ اندروید** | کلاینت VPN با چند هستهٔ واقعی، به‌علاوهٔ فروشگاه کاملی که داخل خود اپ کار می‌کند |
| **ربات تلگرام + مینی‌اپ** | همان فروشگاه از سمت تلگرام: خرید، تمدید، کیف پول، تیکت و مدیریت |
| **پنل مدیریت** | پنل‌ها، پلن‌ها، کاربران، فاکتورها، اعلان‌ها و بکاپ |

اپ با Kotlin و Jetpack Compose نوشته شده، کامل راست‌به‌چپ است و اعداد را فارسی
نشان می‌دهد.

## اتصال

### هسته‌ها و پروتکل‌ها

| هسته | پروتکل‌ها | وضعیت |
| --- | --- | --- |
| Xray | VLESS، VMess، Trojan، Shadowsocks، SOCKS، HTTP | داخل اپ |
| Xray | Hysteria2، WireGuard | داخل اپ |
| strongSwan | IKEv2 | داخل اپ |
| OpenVPN for Android | ورود فایل `.ovpn`، احراز هویت، پروفایل‌های چندتایی | داخل اپ |
| Psiphon | با انتخاب کشور | داخل اپ |
| Tor | `libtor.so` همراه بسته است | داخل اپ |
| SSH | تونل SSH، به‌علاوهٔ SFTP و ترمینال | داخل اپ |
| DNS tunnel | — | **همراه بسته نیست** ([چرا](third_party/dnstt/README.md)) |

> `DnsTunnelController` وقتی موتور نباشد `UNAVAILABLE` برمی‌گرداند و اپ هیچ‌وقت
> تونل را «متصل» نشان نمی‌دهد. این تنها قابلیتی است که در این مخزن ناقص است و
> عمداً این‌طور مانده، نه به‌صورت بی‌صدا.

### انتخاب سرور

| قابلیت | توضیح |
| --- | --- |
| اتصال به سریع‌ترین | همهٔ کاندیداها اندازه‌گیری و رتبه‌بندی می‌شوند، بعد اتصال |
| تست همه | پینگ موازی همهٔ کانفیگ‌ها، و مرتب‌سازی بر اساس نتیجه |
| جست‌وجو، علاقه‌مندی، مرتب‌سازی | روی همان نوار ابزار لیست |
| اتصال خودکار بر اساس شبکه | قانون برای هر Wi‑Fi یا داده |
| چرخش بین سرورها | هر ۱۵، ۳۰، ۶۰ یا ۱۲۰ دقیقه |
| تشخیص عیب اتصال | علت و راه‌حل، نه فقط یک جملهٔ خطا |
| تاریخچهٔ اتصال | ۱۰۰ رویداد آخر |

### ورود کانفیگ

از لینک، QR (دوربین یا تصویر)، فایل، کلیپ‌بورد و لینک اشتراک. فرمت‌های کلاینت‌های
دیگر (از جمله NPVT و NPVS) هم خوانده می‌شوند؛ آن‌هایی که به کلید اختصاصی همان
برنامه نیاز دارند عمداً پشتیبانی نمی‌شوند و صریح می‌گویند چرا.

## فروشگاه داخل اپ

فروشگاه در خود اپ اجرا می‌شود، نه در یک WebView.

| بخش | توضیح |
| --- | --- |
| خرید | پنل، دسته، مدت، پلن — به‌علاوهٔ پلن سفارشی (حجم و زمان دلخواه) و مقایسهٔ پلن‌ها |
| کیف پول | موجودی، شارژ، پرداخت از موجودی |
| پرداخت | درگاه HTTPS در یک Activity جدا، رسید دستی، و بررسی وضعیت از سرور (نه از آدرس بازگشت) |
| ادامهٔ پرداخت | فاکتور نیمه‌کاره از هر تبی دیده می‌شود و همان سفارش ادامه پیدا می‌کند |
| تحویل | ساب یا کانفیگ به‌صورت خودکار وارد می‌شود و به همان سرویس گره می‌خورد |
| تمدید | یک ضربه، از لیست سرویس‌ها یا از خود اعلان |
| اکانت تست | یکی به ازای هر پنل |
| تیکت | ساخت، پاسخ، بستن، دپارتمان‌ها |
| تراکنش‌ها | سابقهٔ مالی، صفحه‌بندی‌شده |
| خروج از حساب | جدا کردن این گوشی و ورود با حساب دیگر |
| کد تخفیف | روی همان صفحهٔ تأیید سفارش |
| **فروشگاه‌ها** | فروشگاه‌های فروشندگان دیگر، با ستاره و درصد رضایت؛ خرید، پرداخت به خودِ فروشنده، و تحویل کانفیگ بدون رفتن به تلگرام |

**ورود** با یک کد از ربات انجام می‌شود؛ توکن با AES‑GCM و کلید Keystore روی
دستگاه ذخیره می‌شود.

## اعلان‌ها

| جا | چه می‌آید |
| --- | --- |
| نوار اعلانات | اخطار حجم، اخطار انقضا، وضعیت فروشگاه، پیام ادمین |
| نوار شناور داخل اپ | همان‌ها، با متن کامل |
| مینی‌اپ | همان صندوق، همان علامت‌ها |

هر اعلان دکمهٔ **خوندم** دارد و یک‌بار زدنش کافی است: علامت روی حساب ثبت می‌شود،
نه روی گوشی، پس در اپ و مینی‌اپ هر دو خاموش می‌شود. اخطارهای تکرارشونده را
**سرور** زمان‌بندی می‌کند، نه ساعت گوشی. اعلان مربوط به یک سرویس، دکمهٔ «تمدید
همین سرویس» را مستقیم روی نوتیفیکیشن می‌آورد.

## آپدیت درون‌برنامه‌ای

| مرحله | خودکار؟ |
| --- | --- |
| پیدا کردن نسخهٔ جدید | ✅ هر ۱۵ دقیقه، در بازِ اپ |
| دانلود APK مناسب همان ABI | ✅ |
| بررسی SHA‑256 | ✅ |
| بررسی یکی بودن امضا با نسخهٔ نصب‌شده | ✅ |
| نصب | ⛔ یک ضربه روی دکمهٔ نصبِ خود اندروید |

اپی که device owner نیست بدون تأیید نصب‌کنندهٔ سیستم نمی‌تواند بسته نصب کند.
«نصب بی‌صدا» ادعای چیزی است که اندروید اجازه نمی‌دهد.

## ساختار

```text
app/                    اپ اندروید و فروشگاه بومی
openvpn/                کتابخانهٔ OpenVPN
strongswan/             هستهٔ IKEv2
browser/                ماژول مرورگر داخلی
native/Aether/          سورس هستهٔ بومی
native/Psiphon/         سورس هستهٔ بومی
third_party/dnstt/      توضیح اینکه چرا موتور DNS tunnel همراه نیست
backend/Faoxima-1.0.0/  بک‌اند، پنل، ربات و مینی‌اپ
docs/release-notes/     یادداشت هر نسخه
```

سورس اصلی روی شاخهٔ `main` است و CI مستقیم از همین مخزن می‌سازد. شرح منشأ در
[SOURCE-POLICY.md](SOURCE-POLICY.md).

## ساخت

- Kotlin، Jetpack Compose، Android SDK
- Android 8.0 به بالا (API 26)
- JDK 17، Android SDK 36، Build Tools 36.0.0
- NDK `27.3.13750724`، SWIG، ninja-build

```bash
./gradlew :app:assembleDebug
```

خروجی Release به تفکیک ABI ساخته می‌شود (`arm64-v8a` و `armeabi-v7a`). امضا از
Secretهای CI یا فایل محلیِ ثبت‌نشدهٔ `keystore.properties` خوانده می‌شود.
**کلید امضا هرگز در مخزن Commit نمی‌شود.**

جزئیات در [Android workflow](.github/workflows/android.yml).

## چیزی که ادعا نمی‌شود

- **DNS tunnel** موتور ندارد و این را صریح می‌گوید.
- **کلاینت ویندوز، مک و iOS** از این مخزن ساخته نمی‌شود.
- **xicmp** روی اندروید به root نیاز دارد و عمداً اضافه نشده.
- **بخش فروشگاه‌ها** روی هیچ نصب واقعی اجرا نشده: هیچ فروشگاهی وصل نشده، هیچ
  پرداختی از درگاهی رد نشده، و هیچ رسیدی به فروشنده‌ای نرسیده. قراردادهای
  ۹ درگاه از سورس فاکسیما خوانده شده‌اند، نه از حافظه — ولی خوانده‌شدن با
  آزموده‌شدن یکی نیست.
- هر قابلیتی که اینجا نوشته شده، در سورس هست؛ **تأیید عملکرد هر کدام روی سرویس
  واقعی به تست روی دستگاه نیاز دارد.**
