# قاجار وی پی ان — نسخهٔ وب (PWA)

نسخهٔ نصب‌شدنی فروشگاه و حساب قاجار برای iOS، اندروید، ویندوز، مک و لینوکس؛ همان ظاهر، تم‌ها، فروشگاه‌ها، پرداخت‌ها و اعلان‌های اپ اندروید (بدون هستهٔ اتصال). خرید که تمام شود، سرویس با یک لمس به هر برنامهٔ VPN نصب‌شده روی همان دستگاه اضافه می‌شود (`APP_LINKS.md`).

## ساخت

```bash
cd web
npm ci
npm run build        # tsc + vite → backend/Faoxima-1.0.0/pwa/
```

## قرار دادن روی هاست

فقط **یک پوشه** اضافه می‌شود و هیچ فایلی از ربات تغییر نمی‌کند:

```
…/Ghajarvpn/app/    ← مینی‌اپ فعلی ربات (دست نمی‌خورد)
…/Ghajarvpn/api/    ← API فعلی ربات (دست نمی‌خورد)
…/Ghajarvpn/pwa/    ← همین پوشه (اپ وب)
```

پوشهٔ `pwa` را کنار `app` بگذار. آدرس اپ: `https://<دامنه>/…/Ghajarvpn/pwa/`

- همهٔ درخواست‌ها نسبی‌اند (`../api/`)؛ هیچ دامنه‌ای داخل بسته نیست.
- ورود کاربر: همان اتصال حساب با ربات که اپ اندروید دارد.
- HTTPS لازم است (برای نصب و اعلان).

## نصب روی دستگاه

| دستگاه | روش |
|---|---|
| اندروید | بنر «نصب» داخل اپ، یا منوی Chrome ← Install app |
| آیفون / آیپد | Safari ← اشتراک‌گذاری ← Add to Home Screen |
| ویندوز / مک / لینوکس | Chrome یا Edge ← آیکن نصب در نوار آدرس |

## اعلان‌ها

- **اپ باز یا در پس‌زمینه**: خوراک اعلان‌های اپ اندروید (`notices.php`) هر ۶۰ ثانیه خوانده می‌شود؛ بنر داخل اپ + اعلان روی نوار اعلانات دستگاه. تنظیمی لازم نیست.
- **اپ کاملاً بسته** (Web Push): فایل‌های `pwa/push.php` و `pwa/push-cron.php` داخل همین پوشه‌اند. فقط یک کرون در پنل هاست اضافه کن (هر دقیقه):

  ```
  php /path/to/Ghajarvpn/pwa/push-cron.php
  ```

  کلیدهای VAPID و جدول‌ها خودکار ساخته می‌شوند. نیاز: `openssl` و `curl` در PHP.
