# قاجار وی پی ان — نسخهٔ وب (PWA)

نسخهٔ نصب‌شدنی فروشگاه و حساب قاجار برای iOS، اندروید، ویندوز، مک و لینوکس؛ همان ظاهر، تم‌ها، فروشگاه‌ها، پرداخت‌ها و اعلان‌های اپ اندروید (بدون هستهٔ اتصال). خرید که تمام شود، سرویس با یک لمس به هر برنامهٔ VPN نصب‌شده روی همان دستگاه اضافه می‌شود (`APP_LINKS.md`).

## ساخت

```bash
cd web
npm ci
npm run build        # tsc + vite → backend/Faoxima-1.0.0/pwa/
```

خروجی کنار `api/` روی همان سرور قرار می‌گیرد:

```
…/Faoxima/Ghajarvpn/pwa/   ← این بسته (آدرس نصب)
…/Faoxima/Ghajarvpn/api/   ← miniapp.php، weblink.php، notices.php، market.php، push.php
```

- هیچ دامنه یا هاستی داخل بسته نیست؛ همهٔ درخواست‌ها نسبی‌اند (`../api/`). اگر سایت پشت دامنهٔ دیگری (CDN یا دامنهٔ واسط) سرو شود، همان دامنه دیده می‌شود.
- صفحهٔ پرداخت درگاه بانکی متعلق به خود درگاه است و آدرس آن را بانک تعیین می‌کند؛ کارت‌به‌کارت و کیف پول داخل خود اپ انجام می‌شوند.
- سرور باید HTTPS داشته باشد (شرط نصب PWA، Service Worker و اعلان).
- `pwa/sw.js` و `pwa/manifest.webmanifest` نباید طولانی کش شوند (`Cache-Control: no-cache`)؛ فایل‌های `assets/` نام هش‌دار دارند و می‌توانند یک‌ساله کش شوند.

## نصب روی دستگاه

| دستگاه | روش |
|---|---|
| اندروید (Chrome/Edge/Samsung) | بنر «نصب» داخل خود اپ، یا منوی مرورگر ← Install app |
| iOS / iPadOS 16.4+ | Safari ← اشتراک‌گذاری ← Add to Home Screen. اعلان فقط در حالت نصب‌شده کار می‌کند |
| ویندوز / مک / لینوکس | Chrome یا Edge ← آیکن نصب در نوار آدرس |

راهنمای تصویری هر دستگاه داخل اپ: تنظیمات ← نصب برنامه.

## اعلان‌ها (روی نوار اعلانات دستگاه)

منبع اعلان‌ها همان خوراکی است که اپ اندروید می‌خواند (`notices.php?action=feed`): هشدار حجم و زمان سرویس، اطلاعیه‌ها و کدهای تخفیف فروشگاه‌ها، وضعیت پرداخت، پاسخ تیکت و پیام‌های همگانی.

1. **وقتی اپ باز است**: هر ۶۰ ثانیه و هنگام برگشتن به اپ خوانده می‌شود؛ بنر بالای صفحه + اعلان سیستمی.
2. **وقتی اپ بسته است**: Web Push.
   - `api/push.php` اشتراک دستگاه را ثبت می‌کند. کلیدهای VAPID بار اول خودکار ساخته و در جدول `ghajar_push_config` ذخیره می‌شوند؛ تنظیمی لازم نیست.
   - کرون زیر را **هر دقیقه** اجرا کنید:

     ```
     * * * * * php /path/to/Faoxima/Ghajarvpn/cronbot/webpush.php >/dev/null 2>&1
     ```

   - اگر سرور به آدرس عمومی خودش دسترسی ندارد، در `config.php` تعریف کنید:
     `define('GHAJAR_PUSH_API_BASE', 'http://127.0.0.1/Faoxima/Ghajarvpn/api/');`
   - نیاز: PHP با `openssl` و `curl`، و مجوز CREATE TABLE روی دیتابیس.
3. دکمهٔ «خوندم» روی اعلان، همان کار اپ را می‌کند (dismiss روی سرور). اعلان تمدید مستقیم صفحهٔ تمدید همان سرویس را باز می‌کند.
4. شمارندهٔ خوانده‌نشده روی آیکن اپ (Badging API) نشان داده می‌شود.

دسته‌های اعلان (عمومی، سرویس، مهم) از تنظیمات ← اعلان‌ها قابل خاموش/روشن‌اند و روی سرور هم اعمال می‌شوند.
