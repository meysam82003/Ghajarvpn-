# افزونهٔ قاجار وی پی ان (کروم و فایرفاکس)

فقط **مرورگر** به VPN وصل می‌شود؛ بقیهٔ برنامه‌ها و کل سیستم دست نمی‌خورند.

## چطور کار می‌کند

- اتصال VLESS / Reality / VMess / Trojan / Shadowsocks را **هستهٔ Xray داخل برنامهٔ دسکتاپ قاجار** انجام می‌دهد. خود افزونهٔ مرورگر نمی‌تواند این پروتکل‌ها را اجرا کند.
- برنامهٔ دسکتاپ فقط یک پروکسی محلی روی `127.0.0.1` باز می‌کند (SOCKS5 و HTTP) و هیچ تنظیم پروکسی یا مسیر سیستم را عوض نمی‌کند.
- افزونه فقط مرورگر را به همان پروکسی می‌فرستد، DNS را هم از داخل VPN می‌گیرد و WebRTC را می‌بندد تا IP واقعی لو نرود.
- اگر برنامهٔ دسکتاپ بسته شود، افزونه خودش مرورگر را به حالت عادی برمی‌گرداند تا اینترنت قطع نماند.
- سایت‌های `.ir` و IPهای ایران به‌طور پیش‌فرض بدون VPN باز می‌شوند (قابل خاموش کردن).
- درگاه کنترل (`127.0.0.1:47823`) فقط به افزونه جواب می‌دهد؛ صفحه‌های وب نمی‌توانند از آن استفاده کنند.

## نصب

1. برنامهٔ دسکتاپ قاجار (ویندوز، مک یا لینوکس) را نصب و اجرا کن؛ در آن یک سرویس انتخاب کن و یک‌بار «اتصال» را بزن تا سرورها بیایند.
2. افزونه:
   - **کروم / اج / بریو:** `GhajarVPN-chrome-extension.zip` را باز کن ← `chrome://extensions` ← «Developer mode» ← «Load unpacked» ← پوشه. برای نصب عادی کاربران باید در Chrome Web Store منتشر شود.
   - **فایرفاکس:** `GhajarVPN-firefox-extension.xpi` را روی پنجرهٔ فایرفاکس بکش. فایرفاکس عادی فقط افزونهٔ امضاشده را نصب می‌کند: کلیدهای AMO را با نام‌های `AMO_JWT_ISSUER` و `AMO_JWT_SECRET` در Secrets مخزن بگذار تا CI خودش آن را امضا کند. بدون امضا، در Firefox Developer Edition یا Nightly نصب می‌شود.

## ساخت و تست

```bash
node build.mjs                     # dist/GhajarVPN-chrome-extension.zip و dist/GhajarVPN-firefox-extension.xpi
XRAY_DIR=<پوشهٔ xray> xvfb-run -a node test/e2e.mjs   # کروم واقعی + هسته + سرور VLESS محلی
```
