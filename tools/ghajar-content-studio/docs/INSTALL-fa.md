# راهنمای نصب — Ghajar Content Studio

ربات قالب‌سازی، مدیریت و انتشار پست کانال **قاجار VPN**.
نصب فقط با **دو ورودی**: توکن ربات و آیدی عددی ادمین.

---

## ۱) پیش‌نیازهای هاست

| مورد | حداقل |
|---|---|
| PHP | **۸.۲ یا ۸.۳ یا ۸.۴** (هر سه پشتیبانی و تست می‌شوند) |
| افزونه‌ها | `pdo`, `pdo_sqlite`, `curl`, `mbstring`, `json`, `openssl` |
| SQLite | ۳.۲۴ یا بالاتر (روی همه هاست‌های PHP ۸.۲+ موجود است) |
| دامنه | **HTTPS فعال** (الزام تلگرام برای Webhook) |
| دسترسی نوشتن | روی پوشه `storage/` |

نیازی به SSH، Composer، MySQL یا Cron **نیست**.

---

## ۲) مراحل نصب

۱. فایل `ghajar-content-studio.zip` را در هاست (مثلاً `public_html/studio/`) استخراج کنید.
۲. در مرورگر باز کنید:
   `https://your-domain.com/studio/install.php`
۳. دو فیلد را پر کنید:
   - **توکن ربات تلگرام** — از [@BotFather](https://t.me/BotFather)
   - **آیدی عددی ادمین** — از [@userinfobot](https://t.me/userinfobot)
۴. دکمه **🚀 نصب و راه‌اندازی ربات** را بزنید.
۵. پس از پیام موفقیت، دکمه **«باز کردن ربات در تلگرام»** را بزنید و `/start` بفرستید.

نصب‌کننده به‌صورت خودکار این کارها را انجام می‌دهد:

- بررسی نسخه PHP و افزونه‌ها
- بررسی HTTPS و تشخیص آدرس سایت
- اعتبارسنجی توکن با `getMe` و اعتبارسنجی آیدی ادمین
- ساخت دیتابیس SQLite + همه جدول‌ها و ایندکس‌ها
- درج تنظیمات اولیه، لینک‌های پایه و ۱۱ قالب آماده
- ساخت `webhook_secret` و ثبت Webhook در تلگرام + تأیید آن
- نوشتن فایل تنظیمات امن و محافظت از `storage/`
- قفل کردن نصب‌کننده

---

## ۳) تنها کار دستی باقی‌مانده: ادمین کردن ربات در کانال

۱. کانال → **Manage Channel → Administrators → Add Admin**
۲. ربات را جست‌وجو و اضافه کنید.
۳. مجوز **Post Messages** را فعال کنید.
۴. در ربات: **⚙️ تنظیمات → 🔍 بررسی دسترسی کانال**

---

## ۴) اگر نصب شکست خورد

نصب‌کننده دقیقاً می‌گوید کدام مرحله شکست خورده است.

| خطا | راه‌حل |
|---|---|
| «نسخه PHP کافی نیست» | از پنل هاست PHP را روی ۸.۲، ۸.۳ یا ۸.۴ بگذارید |
| «نسخه SQLite کافی نیست» | نسخه PHP را در پنل هاست عوض کنید (۸.۲ تا ۸.۴) |
| «cURL بدون SSL» | از پشتیبانی هاست بخواهید cURL با OpenSSL فعال شود |
| «افزونه فعال نیست» | افزونه‌های گفته‌شده را در پنل هاست فعال کنید |
| «HTTPS فعال نیست» | گواهی SSL دامنه را فعال و سایت را روی https باز کنید |
| «storage قابل نوشتن نیست» | دسترسی پوشه `storage` را روی 755 یا 775 بگذارید |
| «توکن نامعتبر» | توکن را دوباره از BotFather کپی کنید |
| «تلگرام آدرس Webhook را تأیید نکرد» | دامنه باید از بیرون با HTTPS معتبر در دسترس باشد |

برای نصب دوباره، فایل `storage/installed.lock` را حذف کنید.

---

## ۵) امنیت

- توکن فقط در `storage/config.php` ذخیره می‌شود و هرگز در خروجی HTML، خطا یا لاگ نمایش داده نمی‌شود.
- `storage/` با `.htaccess` و `index.php` محافظت می‌شود و نام فایل دیتابیس تصادفی است.
- هر درخواست Webhook با هدر `X-Telegram-Bot-Api-Secret-Token` بررسی می‌شود.
- همه پرس‌وجوها با PDO و پارامتر اجرا می‌شوند.
- فقط آیدی عددی ادمین ثبت‌شده به ربات دسترسی دارد (نه Username).
- نصب‌کننده محدودیت تلاش، محافظت CSRF و قفل نشست دارد.

---

## ۶) اجرای تست‌ها

```bash
php tests/run.php      # ۴۵ تست عملکردی (شامل تست واقعی صفحه نصب)
php tests/compat.php   # تضمین سازگاری با PHP ۸.۲ / ۸.۳ / ۸.۴
```

اگر روی هاست خودتان نسخه PHP را عوض کردید، کافی است همین دو دستور را با همان
نسخه اجرا کنید تا از سازگاری مطمئن شوید:

```bash
php8.2 tests/run.php && php8.2 tests/compat.php
php8.3 tests/run.php && php8.3 tests/compat.php
php8.4 tests/run.php && php8.4 tests/compat.php
```
