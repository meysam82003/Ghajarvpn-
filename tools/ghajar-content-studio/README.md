# 👑 Ghajar Content Studio

ربات PHP مستقل برای ساخت، قالب‌بندی، مدیریت و انتشار پست‌های کانال **قاجار VPN**.
نصب با دو ورودی (توکن ربات + آیدی ادمین)، بدون Composer، بدون MySQL، بدون Cron.
سازگار با **PHP ۸.۲، ۸.۳ و ۸.۴**.

📘 راهنمای نصب فارسی: [`docs/INSTALL-fa.md`](docs/INSTALL-fa.md)

---

## قابلیت‌ها

- **نصب‌کننده وب** با تم تاریک قاجار، فقط دو فیلد، ۱۰ مرحله بررسی و قفل خودکار.
- **دریافت پیام**: متن، متن کپی‌شده، فوروارد، ایموجی، لینک و قالب‌بندی تلگرام (bold/italic/link/code/spoiler…) با تبدیل دقیق آفست‌های UTF-16.
- **۱۱ قالب آماده** (اصلی قاجار، تبلیغاتی، رسمی، قابلیت جدید، انتشار نسخه، اطلاعیه، آموزش، معرفی سرور، رفع باگ، مینیمال، اختصاصی) — همه قابل ویرایش، کپی، تغییر نام، حذف و پیش‌فرض‌کردن.
- **ساخت قالب از روی پیام نمونه**: پیام را بفرستید → «ذخیره به‌عنوان قالب جدید» → بخش‌ها (شماره، عنوان، ایموجی، مقدمه، بدنه، فهرست قابلیت‌ها، جمع‌بندی، شعار، فوتر، لینک‌ها) خودکار تشخیص داده می‌شوند و هر بخش را می‌توانید **ثابت یا متغیر** کنید.
- **موتور قالب** با متغیرهای `{number} {title} {body} {features} {apk_url} …` و بخش اختیاری `[[ ... ]]` که با متغیر خالی حذف می‌شود.
- **شماره‌گذاری خودکار**: شماره فقط هنگام انتشار موفق مصرف می‌شود؛ حالت خودکار/دستی/بدون شماره؛ جلوگیری از شماره تکراری؛ بازگردانی شماره در صورت شکست.
- **پیش‌نویس کامل**: پیش‌نمایش زنده، ویرایش متن/عنوان/ایموجی/بخش‌ها/شماره/لینک‌ها، تغییر قالب، متن قابل کپی، تاریخچه ویرایش و بازگشت به نسخه قبلی، جست‌وجو، حذف — همه در SQLite و مقاوم در برابر ری‌استارت.
- **انتشار واقعی**: بررسی ادمین‌بودن ربات و مجوز ارسال، تأیید دومرحله‌ای، قفل انتشار (Publish Token) برای جلوگیری از ارسال تکراری، ثبت Message ID و لینک پیام، مدیریت وضعیت «نامشخص» در قطع ارتباط.
- **مدیریت لینک‌ها**: کانال، ربات، APK، ریلیز، مخزن + لینک‌های دلخواه.
- **مدیریت نسخه APK از GitHub**: بررسی ریلیزها، نمایش تاریخ/معماری/حجم فایل‌ها، انتخاب APK پیش‌فرض، ثبت لینک ریلیز — با تفکیک Draft/Prerelease و حفظ لینک‌های قبلی هنگام خطا.
- **پنل مدیریت فارسی** با Inline Keyboard و ویرایش پیام منو (چت شلوغ نمی‌شود).
- **آمار واقعی** از دیتابیس.

## ساختار

```
install.php          نصب‌کننده وب (دو فیلدی)
webhook.php          نقطه ورود تلگرام (بررسی secret)
index.php            صفحه عمومی خنثی
src/Core/            Config, Database, Migrations, Settings
src/Telegram/        Api, Keyboard, ApiException
src/Support/         Html (entities→HTML), Str, Logger
src/Templates/       TemplateRepository, TemplateRenderer, MessageParser, DefaultTemplates
src/Drafts/          DraftRepository, DraftComposer, PostNumbering
src/Links/           LinkRepository
src/Github/          GithubClient
src/Publishing/      Publisher
src/Bot/             Router, State
storage/             config.php, دیتابیس SQLite, لاگ‌ها (محافظت‌شده)
tests/               run.php (تست‌های عملکردی) و compat.php (سازگاری PHP ۸.۲–۸.۴)
```

## سازگاری PHP

کد فقط از امکانات موجود در PHP ۸.۲ استفاده می‌کند و هیچ الگوی منسوخ‌شده در ۸.۳/۸.۴ ندارد.
`tests/compat.php` این موضوع را ماشینی بررسی می‌کند: نبود نحو و توابع مخصوص ۸.۳/۸.۴،
نبود پارامتر nullable ضمنی (منسوخ در ۸.۴) و اجرای کامل بدون هیچ Deprecated/Warning/Notice.
نصب‌کننده هم نسخه PHP، نسخه SQLite (حداقل ۳.۲۴) و پشتیبانی SSL در cURL را بررسی و گزارش می‌کند.

## تست

```bash
php tests/run.php      # ۴۵ تست عملکردی
php tests/compat.php   # ۷ تست سازگاری PHP ۸.۲ تا ۸.۴
```

۴۵ تست: نصب، امنیت و دسترسی، دریافت/فوروارد پیام، تبدیل entities، ساخت و بارگذاری قالب، ساخت قالب از نمونه، جلوگیری از نشت متن نمونه، فوتر تکراری، شماره‌گذاری، ویرایش عنوان/قالب، undo، انتشار، جلوگیری از انتشار دوباره، خطای GitHub، و تست واقعی صفحه نصب (رندر فرم، CSRF، اجرای مراحل بررسی محیط، قفل نصب‌کننده).
