# قاجار وی پی ان · Ghajarvpn

کلاینت بومی اندروید قاجار وی پی ان با پالت پیش‌فرض سرمه‌ای، سبز قاجاری، آبی یخی و طلایی. بنفش در تم پیش‌فرض و دارایی‌های اصلی استفاده نمی‌شود و فقط می‌تواند انتخاب اختیاری کاربر باشد.

[کانال تلگرام](https://t.me/Ghajarvpn) · [ربات و مینی‌اپ](https://t.me/Ghajar_vpnbot)

## امکانات نسخهٔ اندروید

- پشتیبانی از اندروید ۷ به بعد
- رابط کاملاً بومی Kotlin/Compose و فارسی RTL
- پشتیبانی از VLESS، VMess، Trojan، Shadowsocks، SOCKS، HTTP، Hysteria2، WireGuard و IKEv2
- موتور داخلی OpenVPN، ورود فایل `.ovpn`، احراز هویت تعبیه‌شده یا دریافت نام کاربری/رمز و پینگ پیش از اتصال
- ورود لینک‌ها و اشتراک‌های عمومی سازگار با Happ/Xray
- فروشگاه بومی و پویا متصل به پنل فعلی قاجار؛ قیمت و محصول ثابت داخل برنامه نوشته نشده است
- پرداخت HTTPS داخل برنامه بدون نوار آدرس مرورگر و بدون نمایش نام‌های برند قبلی
- افزودن خودکار سرویس خریداری‌شده یا تست به فهرست اتصال
- پوستر زندهٔ مینی‌اپ برای ورودی برنامه و تصویر آفلاین شاه‌وملکهٔ قاجار
- نمایش اعلان‌های عمومی، شخصی، شناور، پایان حجم و پایان زمان هم داخل برنامه و هم در نوار اعلان گوشی
- اعلان اتصال با آواتار قاجار، نمایش/بررسی پینگ و دکمهٔ قطع اتصال

## ساخت پروژه

پیش‌نیاز: JDK 21، Android SDK 36.1، NDK 28.2 و SWIG.

```bash
./gradlew :app:assembleDebug
```

کلید امضای انتشار باید فقط در Secrets گیت‌هاب یا فایل محلی خارج از Git نگهداری شود.
