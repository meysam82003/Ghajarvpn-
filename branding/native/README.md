# Qajar native assets

The launcher and payment frame are optimized JPEG exports of the user's prior generated Qajar artwork. Numbers, cardholder and amounts are drawn by Android from the actual server response.

`ghajar_royal_characters.webp` is a lossless WebP of a transparent PNG generated with the built-in image tool on 2026-08-28, preserving alpha. The earlier file titled transparent actually had a checkerboard baked into RGB and is not bundled.

Prompt: background-extraction for the existing Qajar king and queen holding the globe; remove only the checkerboard, preserve identities, poses, crowns, costumes, hands, glowing globe and palette; truly transparent alpha, no added text or background.

Legacy launcher density variants are resized from the same branded master. The themed icon uses a separate native crown silhouette instead of tinting an opaque bitmap rectangle.
