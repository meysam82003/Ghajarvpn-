# ربات قجر — نسخهٔ ۲۰ (اپ وب نصبی + رفع قیمت‌گذاری دلاری همهٔ پنل‌ها)

پایه: `ghajar-bot-v19-usd-pricing.zip`. هیچ فایلی حذف نشده و منطق قبلی دست نخورده است.

## تغییرات

| بخش | فایل | توضیح |
|---|---|---|
| قیمت‌گذاری دلاری همهٔ پنل‌ها | `re/rx/admin/pricing.php` | دکمهٔ «💵 قیمت‌گذاری دلاری پنل‌ها» در کیبورد معمولی (غیر شیشه‌ای) متن می‌فرستد نه `fxall_menu`؛ آن متن هیچ پاسخی نداشت. حالا همان متن (حتی وقتی ایموجی استایل حذف شده باشد) منوی گروهی را باز می‌کند. کیبورد شیشه‌ای مثل قبل کار می‌کند. |
| اپ وب نصبی (PWA) | `pwa/` (پوشهٔ جدید) | ظاهر اپ اندروید، فروشگاه‌ها، خرید، تمدید، کیف پول، اعلان‌ها، افزودن به اپ‌های VPN؛ نصب روی گوشی و کامپیوتر. |
| اعلان روی نوار اعلان | `pwa/push.php`، `pwa/push-lib.php`، `pwa/push-cron.php` | Web Push بدون کتابخانه؛ جدول‌ها و کلیدها خودکار ساخته می‌شوند. |
| پرچم سرورها در Happ ویندوز | `pwa/sub.php` | رلهٔ اشتراک برای اپ‌های دسکتاپ؛ پرچم هر سرور را اول نام می‌آورد. فقط آدرس‌های امضاشده و فقط به هاست‌های عمومی. |

## نصب روی هاست

1. فقط این دو مورد را آپلود کن (یا کل پوشه را با نسخهٔ قبل جایگزین کن):
   - پوشهٔ `pwa/` کنار پوشه‌های `app/` و `api/`
   - فایل `re/rx/admin/pricing.php`
2. اختیاری، برای اعلان وقتی اپ کاملاً بسته است، کرون هر دقیقه:
   `php /path/to/Ghajarvpn/pwa/push-cron.php`
3. آدرس اپ وب: `https://<دامنه>/…/Ghajarvpn/pwa/`
